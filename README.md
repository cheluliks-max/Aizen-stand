# Стенд Айзена — «Владыка Небес» (Fabric, Minecraft 1.21.1)

## Что внутри
- **Стрела Стенда** — ПКМ по предмету: тебя пронзает, просыпается стенд (один раз, сохраняется в мире).
- **G** — вызвать / убрать стенд.
- **R** — Хадо №90 «Курохицуги» (чёрный гроб, зажимает цели и бьёт магией ~4 сек).
- **V** — Хадо №99 «Горютенмецу» (пять драконов + взрыв, блоки не ломает).
- **Давление реацу** — пока стенд вызван, всё вокруг (радиус 12 блоков) замедляется, слабеет и прижимается к земле. Не действует на тебя, твоих приручённых и на игроков в креативе.
- **Реацу** — шкала справа внизу. Хадо 90 стоит 35, Хадо 99 стоит 80. Шкала восстанавливается сама.
- Свой дизайн стенда: белая броня с фиолетовым и золотым, камень Хогиоку на груди, крылья-бабочки, вращающееся гало.

Клавиши можно поменять: Настройки → Управление → «Стенд Айзена».
Стрелу можно взять в креативе (вкладка «Бой») или скрафтить:
```
 .  алмаз  .
золото палка золото
 .  перо   .
```

## Как собрать мод (один раз, ~5–10 минут)
1. Поставь **Java 21** (Temurin 21: https://adoptium.net). Проверка: открой терминал, набери `java -version` — должно быть 21.
2. Распакуй этот zip в простую папку (например `C:\aizen_stand_mod`, без русских букв в пути).
3. Открой терминал **в этой папке**:
   - Windows: в проводнике зайди в папку, в адресной строке напиши `cmd` и нажми Enter.
   - Mac/Linux: открой терминал и сделай `cd` в папку.
4. Запусти сборку (при первом запуске скачает много файлов, это нормально):
   - Windows: `gradlew.bat build`
   - Mac/Linux: `./gradlew build`
5. Когда увидишь `BUILD SUCCESSFUL`, готовый мод лежит в `build/libs/aizen_stand-1.0.0.jar`
   (файл с `-sources` в имени не нужен).

## Как поставить
1. Установи **Fabric Loader** для Minecraft **1.21.1**: https://fabricmc.net/use/installer/
2. Скачай **Fabric API 0.102.0+1.21.1** (Modrinth или CurseForge) и положи в папку `.minecraft/mods`.
3. Положи туда же `aizen_stand-1.0.0.jar`.
4. Запусти профиль Fabric 1.21.1.

## Если что-то не работает
- Ошибка при сборке — пришли мне весь текст ошибки из терминала, я поправлю.
- У тебя другая версия Minecraft (не 1.21.1) — скажи какая, перенесу мод.
- Подкрутить силу способностей: файл `src/main/java/com/aizenstand/StandManager.java`, блок `BALANCE` в самом верху.
- Поменять внешний вид: `tools/gen_assets.py` (нужен Python + `pip install pillow`), затем снова `gradlew build`.
